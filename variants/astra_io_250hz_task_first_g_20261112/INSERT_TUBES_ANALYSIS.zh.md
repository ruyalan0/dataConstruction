## 三维夹角定义

用归一化的 wxyz 四元数构造旋转矩阵，所有向量均在同一世界坐标系：

```
t = R_tube * [0, 1, 0]
a = R_wrist * [1, 0, 0]
c = R_wrist * [0, 1, 0]
theta = degrees(acos(clamp(abs(dot(a, t)), 0, 1)))
approach_deviation = 90 - theta
closing_deviation = degrees(asin(clamp(abs(dot(c, t)), 0, 1)))
```

a 是手指接近轴，c 是闭合轴。只要求一个轴垂直会漏掉另一个方向的歪夹；两项均需检查。
绝对值避免管轴正负号造成误判，但不能替代管帽朝上/管尖朝下的独立判断。
不要使用世界 AABB 最长方向、二维投影角、目标关节姿态或管轴与世界竖直的夹角代替上述相对角度。
管和夹爪一同刚性转动时点积不变，因此不能通过“带着管转腕”消除相对歪夹；需要受支撑重抓。
