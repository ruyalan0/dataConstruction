# 自动观测增强的 linear 对照版本

从 `astra_io_250hz_interpolation_compare` 独立复制，运行时选择 linear。
原版代码、已完成记录和已取消任务目录均保留。速度0.6 rad/s、0.7秒参考段、
0.8秒返回上限、夹爪逻辑、物理时钟、任务时限、400次模型预算与原linear一致。

每次RGB观测同时采样当前物体及机器人位姿；不额外推进物理，不增加模型工具。
最多保留0.5仿真秒的位姿历史，在决策边界自动输出 `scene_feedback`：

- 物体相对各腕部的位姿变化、腕部实际移动量、物体速度、相对移动和潜在滑移迹象。
  静止接近不能证明持物，随动也不能排除外部支撑，因此不输出“可靠抓取已验证”。
- 从当前世界网格读取局部几何和主轴，产生带明确限制的几何夹持候选。
  不调用IK、不规划路径、不自动补抓；候选尚未检查可达性、碰撞或力封闭。
- 根据当前物体类别、公开指令与篮子几何，列出每类已入篮、未入篮和混入对象。
  不读取奖励、评分阶段或未来动作；几何完成不等于官方成功或支撑已验证。
- 提供当前关节相对初始姿态的最大误差，保留原始RGB、物体真值和模型memory。

接触力传感未在原场景启用，本版本不改变碰撞、摩擦或传感器配置；接触明确标记不可用。
衣物网格不当作语义材料点，液体位姿或网格缺失明确保留未知，不虚构流量/体积。
所有新增观测持久化到 `scene-feedback.jsonl`，并保存在模型请求及导出记录中。

验证：`../../.venv-policy/bin/python -B -m unittest discover -s tests -q`。
