# 三种插值执行路径对照

独立于 astra_io_250hz_joint_goal 的实验版本；保留同一模型输出协议、任务技能、场景真值、四位小数、5秒4fps历史和250Hz/25Hz时钟。

通过 run_local.py --interpolation-profile native|linear|quintic 选择方法。三组使用同一份解释所有方法的系统提示词；controller与运行元数据明确记录当前方法及实际生效的参考限速标志。

- native：实际调用未修改的 RoboDojo process_control_info，保留默认10个4ms帧及关节/夹爪80%插值、20%保持。生成时使用辅助臂轨迹副本，实际执行才逐周期消费辅助臂，避免提前消费或中断丢失。逐次原生调用证据保存在 seed-*/native-interpolation.jsonl。
- linear：复用旧版线性进度公式，由执行器按0.6rad/s参考速度选择时长。参考最多0.7秒；长目标按比例截取部分。不声称这是包含模型steps的旧版完整执行栈，也不声称线性段满足3rad/s²的参考加速度界限。
- quintic：保留当前五次多项式参考、0.6rad/s及3rad/s²、部分目标段和每段加减速。

共同执行器：0.8秒返回上限，0.1秒稳定窗口，新闭合0.3秒最短正常返回，静态保持0.24秒，既有3mm夹爪变化保护；模型仍只输出关节/夹爪目标，不输出steps或时长。原生任务计数、奖励和交互保持25Hz，物理和测量检查250Hz。

这是三条实际执行路径的闭环比较。方法同时决定参考时长和是否应用新增限速，不能把成绩差全部解释为等时曲线形状的因果收益。当前没有宣称进行固定目标序列的真实接触回放。

离线检查85项通过，包括原生源码函数帧序列等价、夹爪归一化回放、辅助臂逐周期消费和三组任务计时；替身不模拟Isaac真实接触。父版本及644个受保护源文件未改动。

实验入口与完整计划在 runs/interpolation-three-tasks-3layouts-20261027-150430/。三任务各L20/L21/L22，共27场；只使用物理GPU4、5、6、7，每卡最多两个仿真进程。
