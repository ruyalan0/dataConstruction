# 通用非特权 harness：实施与原生时限验证

最新约束：仅本项目 harness；模型仅正式指令、已核查的官方公开任务说明、允许 RGB、自身状态及动作记录。奖励/成功/阶段/对象真值/内部时限均不传模型。由 RoboDojo 自行终止，不设置 harness 环境步或 API 调用上限。单请求 900 秒，最多 5 次瞬态重试。

## 已实现

- 输入隔离回归：额外奖励、对象位姿、深度/分割/标定、隐藏时限不改变实际模型请求。
- 当前三视图固定保留，总窗口 6 图；回查配对存档自身位姿。
- 自身已执行原生步数独立计数，回查/额外观测不计步，恢复从动作记录重建。不报告总/剩余内部步数。
- 完整动作段连续未到位计数、请求/实测位姿、实际位移、队列剩余。只报告跟踪，保留原中断阈值，不自动生成脱困动作。
- 可选证据整理：模型 note 原文、命令、测量结果组成历史记录；明确模型声明未验证，保留不确定/否定原文。压缩前上下文另存档；不使用另一个模型总结，不增加语义真值。
- 新格式从已完成操作边界的 session.json 恢复精确消息；旧格式明确标记重建。不读取 episode-result.json 来恢复策略。
- 官方 Model 接口默认保护图像、报告自身计数和详细反馈；证据压缩需显式开启。

## 配置历史（当前仅运行 evidence）

|配置|新增内容|
|---|---|
|baseline|当前原始会话和最近 6 图，原生终止|
|vision|固定当前视图与回查配对自身位姿|
|steps|vision + 自身已执行步数|
|feedback|steps + 详细跟踪反馈|
|evidence|feedback + 通用证据检查与历史整理|

动作控制不含任务名分支；公开任务说明按已审核完整 instruction 精确匹配。用户取消 baseline 对照后，仅运行当前完整 evidence 覆盖 align、stack、coin、egg、cover。先固定单布局作开发信号，再扩大重复和布局。源码从 Git 导出固定副本，模型和模拟器均从同一副本加载，执行中不热改。

## 资源与存储

本机 8 CPU/32 GiB/无 GPU，单卡 worker 22 CPU/115 GiB/L20 46 GiB，四卡 worker 88 CPU/460 GiB/4×L20 46 GiB；全部无 swap 设备。重负载在 worker。运行时暂存远端 /tmp，再备份 HDFS；原始动作和每步 RGB 写共享 NAS。每条任务独立目录，可恢复，独立失败不抹除。

首轮环境迁移未压缩归档导致根卷空间耗尽，已移除未完成临时文件并恢复未提交源码。失败目录 native-vision-align 保留，不算有效评测。三份旧备份验证 HDFS SHA256 一致后移除本地副本，释放约 2.46 GB，清单见 artifacts/harness-plan/storage-offload.json。

当前测试与实验状态以 docs/progress.md 和各 episode-result.json / exit-status.json 为准。尚未结束的实验不算成功或失败结果。
